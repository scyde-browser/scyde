# SCYDE Browser

Brz, tih, premium preglednik koji štiti po defaultu, za **Windows**, **Android** i **iOS** (.ipa za Feather).

| Platforma | Engine | Shell |
|---|---|---|
| Windows | WebView2 (Evergreen) | Tauri 2 + Svelte 5 |
| Android | GeckoView | Kotlin + Jetpack Compose |
| iOS | WKWebView | Swift (SwiftUI + UIKit) |

Zajednička Rust jezgra (`core/`), zajednički web UI (`web/`).
