# SCYDE Browser

A fast, quiet, premium browser that protects by default, for **Windows**, **Android** and **iOS** (.ipa for Feather).

| Platform | Engine | Shell |
|---|---|---|
| Windows | WebView2 (Evergreen) | Tauri 2 + Svelte 5 |
| Android | GeckoView | Kotlin + Jetpack Compose |
| iOS | WKWebView | Swift (SwiftUI + UIKit) |

Shared Rust core (`core/`), shared web UI (`web/`).
