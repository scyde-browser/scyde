# SCYDE v0.1.0: Phase 0, foundations and design

First pre-release of SCYDE Browser. **This release does not contain a browser yet.** It ships the foundations that the Windows, Android and iOS apps are built on in Phases 1–5.

## What's inside
| Asset | Contents |
|---|---|
| `scyde-icons-v0.1.0.zip` | App icons for every platform: Windows `.ico` (16–256, unplated letter), Android adaptive (transparent background, monochrome for themed icons, legacy densities), iOS 1024 light/dark/tinted with `Contents.json` |
| `scyde-v0.1.0.ico` | Windows icon (the Ember S, no plate or background) |
| `scyde-mark-v0.1.0.svg` | Master SVG of the SCYDE S mark |
| `scyde-design-tokens-v0.1.0.zip` | "Island" design tokens built from `design/tokens` (DTCG): CSS custom properties, Kotlin (Compose), Swift (SwiftUI), JSON |
| `scyde-fonts-ofl-v0.1.0.zip` | Bricolage Grotesque, Geist and Geist Mono (SIL OFL 1.1), with licences |
| `scyde-prototypes-v0.1.0.zip` | Clickable HTML prototypes (desktop and mobile, light and dark) with screenshots |
| `scyde-docs-v0.1.0.zip` | Plan, design system, architecture decisions (ADR-0001–0009), status |

## Highlights
- **Visual direction "Island":** no tab strip, no toolbar. The whole interface is one floating island at the bottom, and the New Tab page is a question you type into ("Where to today?").
- **SCYDE S:** the owner's mark in Ember, as a letter without a plate.
- **Engine strategy confirmed** by five gates:
  - Google sign-in works on WebView2, GeckoView and WKWebView.
  - Windows Shield blocks 100 % of the network fixture and pages load faster than without it.
  - GeckoView WASM matching p99 is 40 µs.
  - iOS compiles 264k rules with a 6 ms cached load.
  - Tauri tab switches complete in under 0.4 ms.
- English only (ADR-0009).
