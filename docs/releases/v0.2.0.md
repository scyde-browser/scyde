# SCYDE v0.2.0: first installable builds

The first SCYDE you can install, on all three platforms. **This is an early test build:** it browses, blocks ads and trackers, and keeps history and settings, but much of v1 is still missing (see "Not yet").

## Downloads
| Platform | File | How to install |
|---|---|---|
| Windows 10/11 (x64) | `SCYDE-v0.2.0-windows-x64-setup.exe` | Run it. It installs per user (no admin). The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC": click **More info → Run anyway**. If the WebView2 runtime is missing, it is downloaded. |
| iOS / iPadOS 16.4+ | `SCYDE-v0.2.0-ios-unsigned.ipa` | Sign and install with **Feather** (or another sideloading tool). |
| Android 8+ | `scyde-0.2.0-arm64-v8a.apk` (most phones), `-armeabi-v7a` (older 32-bit phones), `-x86_64` (emulators) | Allow "Install unknown apps" for your browser or file manager. This build is signed with a **test key**, so a later build cannot update it in place: uninstall it first. |

## What works
- **The island:**
  - on Windows: a floating control strip at the bottom, with back/forward/reload, the address (domain emphasized, inline completion from history), Shield, tabs and a menu
  - on phones: the island at the bottom; swipe left/right to switch tabs and swipe up for all tabs
- **New Tab:** "Where to today?", Shield statistics and your recent pages.
- **Shield:**
  - blocks ads and trackers with EasyList, EasyPrivacy and the uBlock filters, compiled for each platform: DNR rules on Windows, WebKit content rules on iOS, the WASM engine on Android
  - hides ad elements (cosmetic filtering)
  - blocks popups that were not caused by a click
- **Settings:** theme (system/light/dark), accent (Ember, Sky, Periwinkle, Lavender, Mint, Onyx), search engine (DuckDuckGo by default), privacy options.
- **History and bookmarks** (Library), saved on your device. Nothing is synced or sent anywhere.
- **Address bar:** typing a domain, `localhost:3000` or an IP opens it, anything else searches. Lookalike domains (for example a Cyrillic "а" in `аpple.com`) are shown as punycode.

## Not yet
- Windows: the blocked-request counter (only popups are counted), the suggestions dropdown, session restore, downloads panel, find in page, zoom, private window, "set as default browser", automatic updates
- Phones: blocked counters, downloads, private tabs, find in page
- Per-site Shield switches, daily filter updates (the lists ship inside the app), and sync

## Verification
- **Windows:** CI builds the installer, installs it silently and runs a smoke test (internal pages and the `qa/adblock` fixture) with a screenshot. Shield scores **11/11** on the fixture inside the installed app (WebView2).
- **iOS:** CI builds for the simulator, takes screenshots and archives the unsigned `.ipa`.
- **Android:** CI builds per-ABI APKs and runs an emulator smoke test with screenshots.
- **Still to do:** checks on real devices (Feather install, Google sign-in) by the owner.
