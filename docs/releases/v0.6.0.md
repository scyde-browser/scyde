# SCYDE v0.6.0: fixes from looking at the real screens

Until now the iOS and Android screens were only built in CI, never looked at. From this release CI publishes screenshots of every platform, and reviewing them found serious bugs that earlier releases shipped. Install as in [v0.2.0](v0.2.0.md). On Android, uninstall the previous version first.

## Android
- **New Tab, Settings, History and Shield pages were empty.** Every request from these pages to the app failed. They work now.
- **Hiding ad elements by class or id did not work.** A large part of cosmetic filtering was silently lost on Android. Fixed; the test page scores 11/11.
- **New Tab could open as a blank `about:blank`** on a slow first start.

## Windows
- **Shield could miss ads right after opening a tab.** The block lists were reloaded with every new tab, and pages loading in that moment were not blocked. They are now loaded once.
- **The island over the page** is confirmed on a real screenshot: it floats, the page shows around it.

## iOS
- **New Tab was blank on first launch** while the block lists compiled. It now shows at once.

## iOS and Android
- **Tab grid:** cards show a picture of the page instead of an empty tile.
- **New Tab:** no more "0 B saved · 0 min" where the platform cannot measure it.

## Verification
- **Screenshots:** CI publishes them to the branches `ci-shots-ios`, `ci-shots-android` and `ci-shots-windows`; every fix above was checked on them.
- **Windows:** CI starts the app twice and requires the ad-block test page to score 11/11 both times.
- **Android:** the emulator scores 11/11 on the ad-block test page.
- **iOS:** the simulator scores 10/11. The one miss is a same-site frame in the test page; WebKit content rules never block same-site documents. Third-party ad frames are blocked.
- **Not verified:** nothing was run on a real phone.
