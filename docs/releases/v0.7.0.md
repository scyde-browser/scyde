# SCYDE v0.7.0: the basics every browser needs

A review of the whole app found everyday web features that did nothing on phones. Install as in [v0.2.0](v0.2.0.md). On Android, uninstall the previous version first.

## Android
- **Page dialogs work:** alerts, confirmations and text prompts, drop-down lists (`<select>`), file uploads, date and time fields, website sign-in (HTTP auth), "Leave this page?" and "Send the form again?". Before, they silently did nothing.
- **Location, camera and microphone:** a site that wants them asks first; only then does Android ask for the app.
- **Full-screen video:** the island and the system bars go away; back leaves full screen.
- **Downloads:** files are saved to Downloads, with a message when they start and finish.
- **Links for other apps** (`tel:`, `mailto:`, app links) open the right app after a tap.
- **A page that does not open** shows a clear message with "Try again" instead of a blank screen.

## iOS
- **Page dialogs work:** alerts, confirmations and text prompts, titled with the site that asks.
- **Downloads** are saved to Files › SCYDE › Downloads.
- **Links for other apps** (`tel:`, `mailto:`, `sms:`, maps) open the right app after a tap.
- **A page that does not open** shows a clear message with "Try again".
- **Camera and microphone on websites** no longer end the app.

## iOS and Android
- **Welcome screen:** closing it any way no longer brings it back on the next launch.

## Privacy
- No new network requests. Downloads are saved from the page's own response. Location, camera and microphone are asked per site and then by the system (PRIVACY.md).

## Verification
